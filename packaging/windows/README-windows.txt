crcsim для Windows

crcsim-gui.exe - графическая версия, запускается двойным щелчком.
Дополнительные библиотеки не нужны.

crcsim.exe - консольная версия, запускается из cmd или PowerShell:
  crcsim.exe --help

Консольная версия выводит текст в UTF-8 и сама переключает кодовую
страницу консоли. Используйте терминал с поддержкой UTF-8
(Windows Terminal, PowerShell, cmd) и шрифт с кириллицей.
